# Python-Experiments

A working archive of Python code from learning and exploring the language — agent-based models,
Bayesian statistics, control systems, optimisation, queuing, statistical process control, supply chain,
time series, finance, machine learning, dashboards and more.

It is a notebook of experiments rather than a package: notebooks and scripts are kept as they were
written and may depend on older library versions. For finished, tested tools see
[Claude Projects](https://github.com/kathuman/claude-projects) and
[Estay Dynamics](https://kathuman.github.io/estay-dynamics/).
